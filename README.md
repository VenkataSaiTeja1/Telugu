# TET 2A Telugu Mock Test

An interactive Telugu language mock test web application built for TET 2A candidates with topic-wise practice, timed tests, instant feedback mode, and source-derived questions.

## Features

- **Topic-wise practice**: Filter questions across 20+ specialized topics or take comprehensive tests across the entire question bank.
- **Timed & Untimed modes**: Practice under timed conditions or learn at your own pace.
- **Instant feedback**: Option to reveal explanations and correct answers immediately after each question.
- **Result summary**: Comprehensive score breakdown including correct, incorrect, unanswered questions, and time spent.
- **Clean Telugu typography**: Styled using `Noto Sans Telugu` with responsive mobile and desktop support.

## Getting Started Locally

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the local development server:
   ```bash
   npm run dev
   ```

3. Build for production:
   ```bash
   npm run build
   ```

4. Preview production build:
   ```bash
   npm run preview
   ```

## Deploying to Vercel

This repository is ready for deployment on [Vercel](https://vercel.com).

1. Import the repository `https://github.com/VenkataSaiTeja1/Telugu` in Vercel dashboard.
2. Framework Preset will be automatically detected as **Vite**.
3. Click **Deploy**.
